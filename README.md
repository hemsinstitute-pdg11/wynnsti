# Wynsti — Personal Website

Personal branding website for **Wahyudi**, with the identity **Technology Enthusiast & Tradepreneur**.

## Design direction

- Futuristic, dark technology aesthetic
- Neumorphic-inspired surfaces and soft depth
- Coral accent: `#EB5757`
- Cyan supporting accent: `#79D8E8`
- Roboto + Space Mono typography
- Indonesian language
- Responsive desktop and mobile layouts

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve this folder with any static HTTP server.

## Add the profile photo

Place Wahyudi's portrait at:

```
assets/wahyudi-profile.jpg
```

Recommended image: vertical portrait, JPG or WebP, at least 900 × 1200 px. The page currently displays a branded fallback until the photo is added.

## Update contact details

In `index.html`, find the email link in the contact section and replace `hello@wynsti.com` with the preferred contact email address.

## Publish

This is a static website and can be hosted with GitHub Pages, Netlify, Vercel, or any static hosting provider.
